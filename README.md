# calisthenics-app

Личный PWA-трекер тренировок по калистенике.

## Что уже есть
- Чёрно-жёлто-оранжевый мобильный дизайн.
- 4 цели: выход силой, подтягивание на одной руке, Front Lever, горизонт.
- Активная недельная программа для выхода силой.
- Галочки по упражнениям с сохранением в браузере.
- История предыдущих недель.
- Кнопка копирования отчёта недели для анализа прогресса.
- PWA manifest + service worker для работы без интернета после первого открытия.

## Хранение данных
Прогресс хранится локально на устройстве через `localStorage`. Код приложения хранится в GitHub.
